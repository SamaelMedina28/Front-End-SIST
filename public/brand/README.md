# Asset de marca UABC

Este directorio está reservado para el asset oficial proporcionado por FCQI / UABC.

Cuando esté disponible, colocar aquí `uabc-logo.svg` sin modificar sus colores,
proporciones ni contenido. Mientras tanto, `AppLogo` utiliza un placeholder
textual claramente identificado para desarrollo; no se ha inventado ni
descargado un escudo.
